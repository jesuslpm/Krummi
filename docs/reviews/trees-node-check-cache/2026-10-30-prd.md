## Findings

<a id="R1"></a>
### R1 — Minor: C7 overstates the memory-safety guarantee for external file mutation

- **Location:** Objective and context / Product decisions / C7; `docs/prd/krummi/trees-node-check-cache.prd.md:51`.
- **Status:** open.
- **Problem:** C7 includes alteration by a foreign program among its scenarios, then promises that the operation can never exhibit undefined behavior because tree code contains no `unsafe`. That is broader than the inherited guarantee: safe tree indexing cannot preserve the pager's safety assumptions when another program changes a mapped file while references into it remain alive.
- **PRD evidence:** C7 includes “un fallo del hardware o de la memoria, o un programa ajeno, que P16 deja fuera de alcance”, followed by “nunca con un comportamiento indefinido, porque los árboles no usan código no seguro (D12)”.
- **Inherited evidence:** `docs/prd/krummi/krummi.prd.md:48` expressly qualifies D12: “ninguna operación pública provoca comportamiento indefinido, salvo que otro programa modifique los archivos del almacén mientras está abierto”. P16 repeats this exception in `docs/prd/krummi/pager.prd.md:44`.
- **Source evidence:** `crates/krummi-pager/src/pager.rs:349`–355 constructs a shared slice through `unsafe` under the requirement that its bytes are not modified while the reference lives, explicitly excluding foreign writes. `crates/krummi-pager/src/sys.rs:1122`–1126 makes the same assumption for the file mapping. Tree bounds checks do not discharge that lower-layer precondition.
- **Impact / severity rationale:** this is a minor clarity defect in the stated guarantee and risk explanation. The checksum-collision tradeoff itself is explicitly accepted and annotated.
- **Suggestion:** limit the no-undefined-behavior statement to malformed-layout handling under the pager's valid safety assumptions, explicitly preserving the existing P16/D12 exception.

No blocker or major findings were identified.
