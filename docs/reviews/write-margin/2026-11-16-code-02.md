## Pending pre-existing advisory

<a id="R2"></a>
### R2 — pre-existing advisory — reused ScratchWriter snapshots are omitted from version GC

- **Earlier ID:** [2026-11-16-code.md#R2](2026-11-16-code.md#R2).
- **Location:** `crates/krummi-pager/src/scratch.rs:1051–1052`; dependent mark borrow at `:1228`, use at `:1265`; resolution at `docs/reviews/write-margin/2026-11-16-code-resolutions.md:30–37`.
- **Problem and reachable scenario:** the prior reproduction remains valid as a source-level causal argument. In a temporary `Scratch`, retain a reader at tx0, publish v1 of page P, then open a reader and writer at tx1. Publish v2 using that writer and obtain v1 and its mark through `writer.snapshot().page_and_code(P)`. Drop the reader at tx1 while retaining the writer and mark; call `scratch.transfer()`, then use the mark.
- **Independent verification:** the writer registers in `state.writer`, separately from `state.live` (`scratch.rs:650–677`). `publish(&mut self)` leaves its snapshot txid unchanged (`:1508–1526`), and reading after publication is explicitly covered by `scratch_tests.rs:189–197`. GC considers only `live`: the remaining tx0 reader needs neither v1 nor its slot. It removes v1 and `drop(garbage)` at `scratch.rs:792` releases its `Arc<Slot>` directly. This bypasses retirement handling, which does consider the writer. The retained mark borrows that slot's `AtomicBool`; using it accesses freed memory. `transfer(&self)` does not end the outstanding writer borrow.
- **Baseline and scope:** inspected the corresponding code at original feature base `6b49bead4ff8df235559625752fda03bd700bfcb`: the GC omission, reusable writer and unowned page-byte borrow already exist there. The mark inherits the earlier retention defect. No equivalent sequence through normal `Store` operations was established: `WriteTransaction::commit(self)` consumes the transaction and drops its writer (`crates/krummi-tx/src/transaction.rs:510`, `:549–569`). The final follow-up range changes none of this code.
- **Evidence type/requirement:** verifiable causal memory-safety argument, not an executed use-after-free experiment; safe encapsulation under root D12 and pager P16, and snapshot/version retention rules. Passing ordinary snapshot tests does not cover this omitted-writer case.
- **Classification:** pre-existing memory-safety advisory; still open, outside the introduced-change approval verdict. Its disposition as pending separate work is supported; it is not verified resolved.
- **Suggestion:** address writer-snapshot retention or the post-publication `ScratchWriter` contract in the separate pager follow-up.
