### R2 — pre-existing advisory — reused ScratchWriter snapshots are omitted from version GC

- **Earlier IDs:** [original R2](2026-11-16-code.md#R2), [first follow-up R2](2026-11-16-code-02.md#R2). Classification remains a pre-existing memory-safety advisory.
- **Locations:** `crates/krummi-pager/src/scratch.rs:1051–1052`; mark borrow at `:1228` and use at `:1265`. Pending resolution: `docs/reviews/write-margin/2026-11-16-code-resolutions.md:30–37`.
- **Scenario and evidence:** the earlier source-level reproduction remains valid. In a temporary `Scratch`, retain a tx0 reader, publish v1 of page P, then open a tx1 reader and writer. Publish v2 through that writer and obtain v1 and its mark through its unchanged tx1 snapshot. Drop the tx1 reader, retain the writer/mark, and call `scratch.transfer()`. GC sees the tx0 reader, which does not need v1, but omits the writer that still does. It drops v1 directly; subsequent use of the borrowed mark accesses the freed slot's `AtomicBool`.
- **Independent source verification:** writer registration goes to `state.writer`, separately from `state.live` (`scratch.rs:650–677`). `publish(&mut self)` leaves the writer's snapshot unchanged (`:1508–1526`), consistent with `scratch_tests.rs:189–197`. `collect_garbage` checks only `self.live`, releases accounting and returns the dropped versions (`:1037–1074`); `flush_locked` drops them at `:792`, bypassing the retirement path that accounts for the writer. `page_and_code` returns unowned page/mark borrows after releasing the state lock (`:1214–1229`). `transfer(&self)` does not end the outstanding borrow. This is a verifiable causal argument, not an executed use-after-free experiment.
- **Baseline/dependent invariant:** the underlying writer omission and post-publication reuse existed at original feature base `6b49bead4ff8df235559625752fda03bd700bfcb`; the new mark inherited an earlier unowned page-borrow retention defect. The present correction range changes none of it. Normal `WriteTransaction::commit(self)` consumes and drops the writer (`crates/krummi-tx/src/transaction.rs:510`, `:549–569`); no equivalent normal `Store` sequence was established. Root D12, pager P16 and snapshot-retention guarantees remain the relevant safety contracts.
- **Status:** still open; not verified resolved. The pending separate-work disposition is accurate. No escalation to an introduced defect is warranted.
- **Suggestion:** address writer-snapshot retention or the post-publication `ScratchWriter` contract in the separate pager follow-up.
