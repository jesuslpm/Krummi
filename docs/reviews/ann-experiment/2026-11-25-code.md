Thus IVF is measured after SQ8 work in the same process, inheriting its allocation history. Fresh processes for different datasets/metrics avoid the earlier cross-metric reuse, but do not provide the per-structure isolation claimed here. The IVF delta remains useful observed process growth; neither this evidence nor the review establishes how much its value would change in an isolated run.
