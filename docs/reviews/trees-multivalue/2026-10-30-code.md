### R1 — Minor: Oscillating measurement panics when the new sizes leave no initial values

- Location: `crates/krummi/examples/multi_timing.rs:670` (new size-dependent threshold calculation), with initialization at `:678` and failing opening at `:692`.
- Status: open.
- Failure scenario: run the oscillating load with 64-byte keys and 1024-byte values, both accepted by the new options and used in the follow-up measurements. With the default first pair, 512:448, one value has volume `64 + 3 + 2 + 1024 = 1093`, so `at_threshold` remains zero. The initialization loop iterates over an empty slice and never executes its only `OpenOrCreate`. The timed loop calls `open_multi_tree` on the absent tree; `TreeNotFound` reaches `expect` and panics before any measurement row is produced. A normal run including all default loads will eventually abort at this load as well.
- Evidence type: coordinator reproduction, supported by the source-level causal chain above. After building the example, this command failed with the default six pairs:

  ```powershell
  & target/debug/examples/multi_timing.exe --loads oscillating --values 10 --key-size 64 --value-size 1024
  ```

  Observed output included:

  ```text
  open the tree: TreeNotFound
  ```

  The panic identified `multi_timing.rs:692:48`; the command runner reported exit 1. A second reproduction, `cargo run --locked -p krummi --example multi_timing -- --loads oscillating --pairs 512:256 --values 10 --key-size 512 --value-size 8`, also failed; Cargo reported child exit 101.
- Requirement: L21 authorizes configurable key/value sizes; the example documents the oscillating load for every selected pair. It supports M15 and S19–S20 / AC-M19–AC-M20. This finding concerns the expanded example, not the validity of historical measurements made with explicitly selected non-oscillating loads.
- Introduction and impact: the base could already reach an empty initialization with unusually small custom thresholds and fixed 16-byte data. The new options introduce this failure for the standard candidate pairs and the requested larger sizes, which the base could not accept. Impact is limited to the manual measurement utility; no engine data-integrity defect is established.
- Suggestion: create and commit the empty tree before the initial-value loop, including when `at_threshold` is zero.

No blocker or major finding was established in the requested range.
