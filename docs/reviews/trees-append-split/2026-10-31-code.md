### Retained height with long separators

L6 records a performance limitation exposed for additional insertion histories. A one-key branch with a 2,048-byte separator occupies 2,076 bytes, above the existing quarter-full threshold of 2,044. D4 therefore does not require its merger. The tree PRD explicitly leaves “la política de división y fusión de páginas y su grado de llenado” to implementation. AC-V6 requires a workload that exercises height changes while checking snapshot stability, rather than minimal height after every deletion history. Its adjusted test still exercises growth, shrinkage and later increasing insertions while an old read survives. No violated contract was established here, so this is contextual evidence, not an additional finding.
