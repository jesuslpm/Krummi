### R2 — original severity minor — Verified resolved

- **Original:** [2026-11-26-code.md#R2](2026-11-26-code.md#R2), concurrent first calls race during shared repository initialization.
- **Fix location/version:** `scripts/runner/runner.sh:28-33` at the head above; caller dependency at `scripts/runner/Invoke-Linux.ps1:50-58`.
- **Independent experimental verification:** repeated the original cold-start race with real Git for 150 pairs/300 invocations per version. Base produced 70 failures with exit 128, including `fatal: cannot mkdir .../repo.git: File exists`; head produced zero failures, with all 150 resulting repositories recognized as bare. The coordinator independently ran another 30 head pairs/60 invocations: zero failures.
- **Deterministic ordering check:** while holding `init.lock` with an incomplete `repo.git` already present, a head initializer waited; after initialization completed and the lock was released, it exited 0. Thus the readiness check is inside mutual exclusion, not merely the creation command.
- **Error-path check:** a simulated Git failure before repository creation propagated exit 73; a subsequent invocation with real Git exited 0, demonstrating lock release on that failure path. This does not claim recovery from every kind of interrupted Git initialization.
- **Dependent lifecycle checks:** during an active task, `init` exited 0 and `init.lock` was available, while a competing run exited 3. After terminating only the wrapper with SIGTERM, a competitor still exited 3; after the task and `tee` completed, the next run exited 0. The separate initialization lock therefore did not introduce premature execution-lock release or make normal initialization fail during a run in these scenarios.
- **Technical basis:** the subshell releases descriptor 8 before the `init` exit or acquisition of descriptor 9's run lock. Initialization remains compatible with the caller's `Assert-Success`; busy reporting remains at `runner.sh:56-57`, matching `docs/linux-runner.md:46-47`. No S#/AC applies.
- **Status:** verified resolved.
