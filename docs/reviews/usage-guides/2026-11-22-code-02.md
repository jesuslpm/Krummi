## Revised pre-existing advisory

Fix commit `a172447d097ecf771b9deb97c4713e2410182c16` qualifies rollback in `docs/guides/errors.md:369`–374 and `docs/guides/rows.md:498`–501. The revised text correctly separates a failure before commit, which aborts the load, from an I/O failure while writing the commit, whose outcome is unknown and never partial.

`crates/krummi/src/table/bulk.rs:109`–135 creates one write transaction, returns early on source/row errors and calls durable `write.commit()` for a nonempty successful source. The transaction owns all row/count/sequence changes. The revised caveat agrees with schema PRD E13 and `WriteTransaction::commit` at `crates/krummi/src/lib.rs:1604`–1615. The underlying `commit_with` in `crates/krummi-tx/src/transaction.rs` publishes only after its point of no return, releases the write turn and then waits for durability.

Independent checks covered the 15 existing bulk-load tests, including aborts on source/row failure, cancellation, panics and preservation of prior state. The existing transaction recovery test `ac12_a_failed_journal_flush_refuses_writes_and_reopening_recovers` was also rerun: it injects a journal synchronization failure, verifies `Io` and refusal of later writes, then reopens and requires both changed pages to be present together or both absent. It passed. This corroborates the revised caveat without changing or reopening the pre-existing blanket promise in `bulk.rs:31`–32.
