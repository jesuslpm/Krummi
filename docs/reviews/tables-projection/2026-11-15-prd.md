## Findings

### R1 — Major: copied rows have incompatible output-lifetime contracts

- **Sections and IDs:** Product decisions / PY3; Output; Acceptance criteria / AC-PY10.
- **Location:** `docs/prd/krummi/tables/tables-projection.prd.md:39`, `:93`, `:194`.
- **Status:** Open.

PY3 expressly includes «también una **fila copiada** por la aplicación» and promises «se devuelven igual: sin copia el texto, los bytes y los vectores». Output additionally requires «con la forma y los préstamos de leer la columna por su posición». For copied rows, existing positional access returns independent owned values, rather than borrowing the copied row. The two promises therefore leave different public ownership/lifetime contracts possible.

**Source evidence:** `TableRow::into_owned` returns `TableRow<'static>` and retains owned values (`crates/krummi/src/table/rows.rs:991`). Positional `value` clones values in the owned branch (`:943`, `:962`). Typed accessors use that branch through `self.value(position)` (`:1050`), and the text and bytes accessors return the resulting `Cow` (`:1148`, `:1151`). `Value` derives `Clone` and stores text, bytes and vectors in `Cow` (`crates/krummi/src/table/value.rs:282`). Consequently, existing results obtained from a copied row can survive destruction of that row.

**Observable readings:**

1. Preserve the existing positional output ownership and independent lifetime for copied rows, copying variable-length contents when returning them.
2. Follow the no-copy requirement by borrowing variable-length contents from the copied row, so those results cannot outlive their owner.

This affects what application code compiles and whether reading allocates/copies. AC-PY10 checks only value equality after a transaction change and rejection of another schema; it does not distinguish the two contracts. The ownership/lifetime choice is absent from *Left to the implementation*.

**Suggestion:** Define the owner and lifetime of projected text/bytes/vector results from copied rows explicitly, and add an acceptance check for that contract.
