<a id="R5"></a>
### R5 — Major: colliding transfer can suppress Q4's debug validation

**Location:** `crates/krummi-pager/src/checked.rs:129`, `:144–145`, interacting with `crates/krummi-tree/src/lib.rs:310–311`.

**Introduced by:** the replacement of R4's map with per-slot provenance in `cf8fd80072a3fc2889df9a49dcbf607e05ec38bc`.

The cached-node decision reads two separate atomic locations. A reader can find page A's code in `Checked::contains`; the transfer can then write a different node B whose page number maps to the same slot, clearing/replacing A's provenance; the reader's subsequent `layout_kept(A, codeA)` returns false. The tree consequently accepts the earlier cache hit without the additional layout validation required for a Q3 leaf.

**Concrete scenario:** A has already been transferred from a version retaining its check. B is a different node at `A + 65536`, committed before the reader's snapshot, still awaiting transfer, with its layout checked. A remains stable to that snapshot; B is eligible for transfer because its commit is no newer than the oldest snapshot (`scratch.rs:810–818`). Interleave the transfer's `remember_written(B, codeB, false)` at `scratch.rs:842–845` between the tree's `is_checked(A)` and `layout_kept(A)`. The normal table's slots repeat every 512 MiB of page numbers, a realistic store size; no checksum collision is needed. An invalid layout introduced by the faulty same-length overwrite that Q4 is meant to catch can then pass this read instead of producing damage.

**Evidence: executed isolated reproductions and source-level causal argument.** A two-thread barrier probe compiled the actual head `checked.rs`, using an allocator-only shim, and observed:

```text
a=100 b=65636 initial_hit=true kept_after_other_transfer=false skips_q4=true
```

A second probe used the actual `Checked` implementation and built `krummi_tree::get` through an isolated `PageSource` adapter. The adapter returns the same malformed leaf in both cases and deterministically inserts B's remembering operation between the two lookups. An empty leaf with a nonzero hole count fails the actual node validator (`node.rs`, `cells_are_valid`), while preserving the leaf kind and level. Observed results:

```text
collide=false tree_get=Err(Damaged { folder: None, page: Some(100) })
collide=true tree_get=Ok(None)
```

Both probes exited 0 with their assertions satisfied. They isolate the cache/tree interaction; they are not an end-to-end `Store` corruption experiment. The source trace above establishes that the inserted operation is reachable through a concurrent real transfer. The pre-fix map was keyed by the full page number, so remembering B did not remove A's provenance.

This occurs even under sequential consistency. Initial publication synchronization through the scratch lock/version filter does not prevent a later colliding transfer: `Snapshot::page_and_code` releases its guard at `scratch.rs:1279` before these tree calls. Merely strengthening `Relaxed` does not fix the demonstrated interleaving. The new `debug_reads_of_kept_and_checked_leaves_run_at_once` test pauses transfer during its reader phase and does not force colliding pages, so its success does not cover this case.

**Requirement:** S1/Q4 of `docs/prd/krummi/pager/pager-written-pages.prd.md`: «En las compilaciones de depuración, toda lectura por otra transacción de una hoja que conserva su comprobación por Q3, en el área temporal o en el archivo de datos, comprueba además su organización, fuera de las comprobaciones que cuentan los criterios, como la anotación del 2026-11-09 a H1; si falla, la lectura falla con la clase de daño y el número de su página; si pasa, no se recuerda nada más.» The failed-read guarantee is lost in debug builds; no release-build regression is alleged.

**Suggestion:** Treat uncertain/evicted provenance conservatively or make the cache-hit/provenance decision coherent, preserving C6's nonblocking constraint, and test the colliding-transfer interleaving.

## Reproducing R5's tree result

The following is the standalone source passed to `rustc` through stdin. Compile after the workspace build with `--edition=2024 -L dependency=target/debug/deps` and `--extern` arguments for the matching debug `krummi_tree`, `krummi_tx` and `krummi_pager` rlibs. The executed artifact was `target/review_q4_tree_probe.exe`. It uses the actual head `Checked`, the repository's allocator, and the built tree code; the adapter controls only page delivery and the colliding operation's timing. No store or source file is created.

```rust
use krummi_tx::{Error, PageCheck, Result, PAYLOAD_SIZE};
mod error { pub use krummi_tx::Result; }
mod scratch { pub use krummi_pager::try_reserve; }
#[path = "C:/projects/Krummi/crates/krummi-pager/src/checked.rs"]
mod checked;
const A: u64 = 100;
const CA: u64 = 0x1234_5678_9ABC_DEF0;
struct Source { checked: checked::Checked, bytes: [u8; PAYLOAD_SIZE], collide: bool }
impl krummi_tree::PageSource for Source {
    fn page(&self, _: u64) -> Result<&[u8]> { Ok(&self.bytes) }
    fn page_and_check(&self, _: u64) -> Result<(&[u8], PageCheck<'_>)> {
        Ok((&self.bytes, PageCheck::Verified(CA)))
    }
    fn is_checked(&self, p: u64, c: u64) -> bool { self.checked.contains(p, c) }
    fn layout_kept(&self, p: u64, c: u64) -> bool {
        if self.collide {
            self.checked.remember_written(A + checked::CHECKED_SLOTS as u64, 99, false);
        }
        self.checked.layout_kept(p, c)
    }
    fn run(&self, _: u64, _: u64) -> Result<&[u8]> { unreachable!() }
    fn slot(&self, _: usize) -> Result<u64> { unreachable!() }
    fn may_hold_data(&self, _: u64) -> bool { true }
    fn may_hold_run(&self, _: u64, _: u64) -> bool { true }
    fn damaged(&self, p: u64) -> Error {
        Error::Damaged { folder: None, page: Some(p) }
    }
    fn fail(&self, e: Error) -> Error { e }
}
fn main() {
    for collide in [false, true] {
        let checked = checked::Checked::new().unwrap();
        checked.remember_written(A, CA, true);
        let mut bytes = [0; PAYLOAD_SIZE];
        bytes[0] = 1;
        bytes[4..6].copy_from_slice(&(PAYLOAD_SIZE as u16).to_le_bytes());
        bytes[6..8].copy_from_slice(&1u16.to_le_bytes());
        let source = Source { checked, bytes, collide };
        let result = krummi_tree::get(&source, A, b"x");
        println!("collide={collide} tree_get={result:?}");
        if collide { assert!(matches!(result, Ok(None))); }
        else { assert!(matches!(result, Err(Error::Damaged { page: Some(A), .. }))); }
    }
}
```
