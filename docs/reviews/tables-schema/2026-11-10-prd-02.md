### R4 — major — Error selection mixes schema order and input order without defining their interaction

**Location:** Decisions / E17; Acceptance / AC14. `docs/prd/krummi/tables/tables-schema.prd.md:52`, `:262`.

**Lineage and reviewed fix:** [Original R4](2026-11-10-prd.md#R4); resolution R4 in `2026-11-10-prd-resolutions.md:38`; fix `af09c4de3071e1e75039b7eb3b4e5b1c85e0489f`.

**Verified improvement:** The original reproduction, `[(id,1),(n,NULL),(n,5)]` with nonnullable `n`, now has an oracle: for that column, the ordered rule list reports `columna repetida` before `nulo no admitido`.

**Remaining problem and evidence:** The correction also adds an input-order exception to the column selector: «Si una fila incumple varias, se informa la primera columna en el orden del esquema (una columna repetida, en el orden en que se dio) y, para ella, la primera regla en el orden de esta lista.» It does not specify how to combine the two orders when a repeated column competes with a different invalid column. AC14 now explicitly requires a result for violations in two columns.

**Documentary reproduction:** Define schema order `id, a, b`, with `id` the primary key and `a` and `b` nonnullable integers. Insert:

```text
[(b,2),(b,3),(id,1),(a,NULL)]
```

**Allowed readings and observable results:**

- Select the first invalid column by schema order, then its first violated rule: `valor no válido`, column `a`, rule `nulo no admitido`.
- Apply the parenthetical as an exceptional input-order check for repetitions before validating the other columns by schema order: `valor no válido`, column `b`, rule `columna repetida`.

The rule order for one column does not decide between these results. Two repeated columns alone would not demonstrate the gap, because the parenthetical can reasonably settle that case by input order; the mixed fixture exposes the missing interaction. This is a regression in R4's correction, so R4 remains open despite resolution of its original example. No executable table API exists yet; this reproduction checks the requirements' oracle.

**Suggestion:** Specify one total selection order across invalid columns, including repeated inputs, and add this mixed case to AC14.
