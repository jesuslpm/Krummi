# JSONTestSuite

The `test_parsing` files of Nicolas Seriot's JSONTestSuite, https://github.com/nst/JSONTestSuite, commit
`1ef36fa01286573e846ac449e8683f8833c5b26a` (2024-11-22), MIT license (`LICENSE`). Used by the tests of the JSON
reader (AC-JS11 of `docs/prd/krummi/tables/tables-json.prd.md`): `y_` files must be accepted, `n_` files
rejected, and each `i_` file has a pinned outcome.
